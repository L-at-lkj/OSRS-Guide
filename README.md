# OSRS Guide Company

A minimal-trust, multi-agent "company" built on Claude Code. It produces **immersive, interactive HTML guides for Old School RuneScape Hardcore Worlds**:
- level-by-level routes that account for everything released in the last 12 months;
- a **Danger Score on every step**;
- next-step decision points with justified options;
- an audit trail of everything every agent did.

```
/osrs-guide Agility 57-99 for hcmbtw          ← produce a guide
/osrs-refresh agility-1-99-20261119           ← re-check a released guide after game updates
```

## Quick start
1. Start Claude Code **in this folder** (`cd osrs-guide-company && claude`). Hooks, agents and skills load at session start. In a cloud session, put this folder in a GitHub repository and start the session on it.
2. The network must reach `oldschool.runescape.wiki`, `secure.runescape.com`, `prices.runescape.wiki` and `sync.runescape.wiki` (already allowed in your Default cloud environment).
3. Run `python3 tests/selftest.py`. It should end with `ALL PASS`.
4. Run `/osrs-guide <your request>`.

## The team (14 agents + Director + observer)
| Division | Roles |
|---|---|
| Client desk | Intake Officer |
| Intelligence | Patch Sentinel (last 12 months), Methods Analyst, Quest Archivist, Threat Analyst, Logistics Analyst |
| Verification | Fact Verifier (independent re-fetch of every claim) |
| Strategy | Route Strategist (no web), Quant (reviews the deterministic XP engine) |
| Safety | Risk Officer (8-factor Danger Score, veto), Red Team (tries to get you killed) |
| Production | Guide Author (no new facts or numbers), Experience Designer (presentation only) |
| Release | QA Auditor (live spot-checks, signs the release; authored nothing) |
| Observer | Sentry hook: logs and polices every tool call |

Read `docs/02-org-chart.md` for mandates and the RACI, and `docs/03-trust-model.md` for the 20 controls.

## Layout
```
CLAUDE.md                     Director's constitution
.claude/agents/*.md           14 role charters (generated by scripts/build_agents.py)
.claude/skills/osrs-guide     Director runbook (/osrs-guide)
.claude/skills/osrs-refresh   maintenance runbook (/osrs-refresh)
.claude/settings.json         Sentry hooks + permissions
docs/01..09                   charter, org chart, trust model, pipeline, danger model,
                              sourcing policy, Hardcore Worlds baseline, UX spec, audit guide
schemas/*.schema.json         handoff contracts (every one requires provenance)
tools/                        ledger · sentry · wiki · hiscores · xp · danger · validate ·
                              assemble · render · audit · browser_check
templates/guide.html          the interactive guide shell
tests/selftest.py             end-to-end and attack tests of every control
jobs/<job>/                   one folder per guide (ledger, dispatches, artifacts,
                              guide.html, audit.html)
audit/actions.jsonl           Sentry's hash-chained log of every action
```

## Your account defaults
Hardcore Worlds · standard account (HW GE) · member · zerker build (**Defence cap 50**, Defence XP from quests only, no lamps into Defence) · danger cap **44** · hiscores board `hiscore_oldschool_hardcore_mains`.

## Auditing
Start with `docs/09-audit-guide.md`. In short:
- `python3 tools/ledger.py status <job>`
- `python3 tools/audit.py timeline <job> [--role X]`
- `python3 tools/audit.py crosscheck <job>`
- open `jobs/<job>/audit.html`

Every guide also has an **Audit trail** tab.

## Changing the company
Policy files are write-protected. Run `OSRS_GOVERNANCE_MODE=1 claude` to edit agents, tools, schemas or docs. Edit `scripts/build_agents.py`, not the generated agent files. Everything you do is still logged.
